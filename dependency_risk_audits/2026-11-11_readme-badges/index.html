Dependency data-risk audit: README badges (shields.io)

2026-11-11. For the project owner. Scope: the nine badge images at the top of README.md, loaded from img.shields.io.

Summary: 1 item, low / metadata only. The host's own logging policy could not be confirmed: see the callout.

Needs a decision or a mitigation

Not confirmed: shields.io's logging of requests. A web search found no official shields.io privacy statement, and nothing on how GitHub's image proxy handles README images. Two privacy pages found were for unrelated mirror hosts and were not used. The expected exposure is the viewer's IP address and browser details reaching a third-party host when the README is opened, or GitHub's servers instead of the viewer if GitHub proxies the images. Neither was verified.

Mitigations already in place: the badge URLs are static (label, version, colour, logo name) and carry no project data, tokens or repository details, and nothing in the app itself loads them: only the README page does. If this exposure matters, remove the badges from README.md: nothing else depends on them.
