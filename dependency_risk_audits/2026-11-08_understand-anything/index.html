Dependency data-risk audit: Understand-Anything

2026-11-08. For the project owner. Scope: what running /understand-anything:understand brings in.

Summary: 1 content-exposure item (mitigated), 3 low or metadata-only, 1 group with no structural risk. No training-risk verdict could be confirmed or ruled out: see the first callout.

Needs a decision or a mitigation

Content exposure: the plugin sends project files to the AI model. Its analysis agents read source files in this Claude Code session, so that content goes to Anthropic. This is the same destination as any Claude Code session on this project, not a new third party. The plugin's own code adds no other destination for this command.

Not checked: whether this account's data may be used for model training. That depends on the account's settings, which this audit cannot see. The owner can check them in the Claude account's privacy settings.

Secrets are not excluded by default. .env and *.pem are absent from DEFAULT_IGNORE_PATTERNS, appear only as commented-out suggestions in the generated .understandignore, and the scanner classes .env files as config to analyse.

Mitigation applied: these patterns are switched on in .ua/.understandignore and must be confirmed against the scan's file list before analysis. No .env file other than backend/.env.example was found within four folder levels of the project root, excluding dependency folders.
