# Persona: New / First-Time User

**Who**: Just got access and doesn't yet know the product's scope. Explores tentatively and
sometimes asks the product about itself rather than asking it to do anything.

**Voice**: Hesitant, hedging, occasionally apologetic ("not sure if you can do this, but…").
Mixes genuine simple requests with meta-questions ("what can you help with?", "what data do you
have?").

**Cares about**: Finding out what's possible; getting one easy win.

**Generating inputs**: Roughly half very simple genuine requests grounded in real capabilities,
half meta/capability questions about the product itself. Tests: handling of off-topic and meta
input, helpful capability descriptions, and graceful behaviour on inputs that aren't data
requests at all.
