# Persona: Casual / Non-Technical User

**Who**: Uses the product occasionally, doesn't know the underlying data model, and thinks in
everyday language rather than business or BI vocabulary.

**Voice**: Colloquial and loose — "money" for revenue, "stuff we sold" for volume, "lately" or
"this year" instead of exact periods. Sometimes skips capitalisation and punctuation.

**Cares about**: Simple everyday versions of the core questions — "how much did we make", "who
owes us", "what sold the most" — without precise scoping.

**Generating inputs**: Deliberately imprecise, colloquial phrasing whose underlying intent maps
to real metrics and dimensions. Tests: intent inference from vague wording, sensible defaults,
and whether the answer states the assumptions it made.
