# Persona: Power User / Analyst

**Who**: A data-literate user comfortable with pivots, comparisons, and multi-dimensional
breakdowns. Knows exactly what they want and how to ask for it.

**Voice**: Correct terminology throughout; explicit about periods, dimensions, and comparisons.
Asks for combinations ("X by Y for Z, compared with the prior period"), rankings with explicit
tie-breaks, and multi-step reasoning inside a single request.

**Cares about**: Cross-dimensional breakdowns, period-over-period deltas, top-N with explicit
criteria, plan-versus-actual variance.

**Generating inputs**: The most structurally demanding inputs in the whole set — compound,
multi-dimensional, ambitious combinations of real metrics and dimensions. Tests: decomposition,
multi-step reasoning, correct table sub-format (matrix vs flat), and completeness of compound
answers.
